### 👋 About me

I spent six years as an accounting technician before switching to software at **42 Porto**. Today I build products for people who work with numbers, and I teach others how to build too.

- 🧾 **Building [Tenanta](https://tenanta.pt)**: a cloud-native, multi-tenant platform for Portuguese accounting firms. Client records, fiscal deadlines, control maps and payment guides in one place.
- 🎓 **Teaching**: Workshop Leader at **TUMO Porto** (game dev, AI, programming) and AI trainer at **Shaken Academy**.
- 🎮 **Making games**: game jams with friends, and a co-op restaurant game in the works.

### 🧾 Tenanta under the hood

- **.NET 9** Minimal APIs + Dapper + **PostgreSQL 16**, Keycloak (OIDC), MinIO / S3
- **React 19** + TypeScript + Tailwind v4 + TanStack Query
- Roles and permissions generated by **C# source generators** from TOML; error catalogue generated from YAML
- Generic CRUD with a search DSL shared between backend and frontend
- **Kubernetes** + NGINX, deployed and versioned with GitHub Actions
